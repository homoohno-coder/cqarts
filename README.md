# cqarts

Unofficial design study for Christina Quarles: an animated landing page (`index.html`) that enters the Gallery design study (`design-study/`), plus a CV page.

Static site (no build step). Artwork images are loaded from the artist's existing image host; the landing page ships its own short looping gallery video and still in `media/`. Excluded from search engines (robots meta + robots.txt).

Edit the `CONFIG` block at the top of the script in `index.html` to change the final image (`hero`, `heroPos`), the artwork groups, or the exhibition list.
